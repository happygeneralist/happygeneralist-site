## Stub

User needs drift is a working term for the pattern where a user need becomes misaligned from the evidence, context or outcome that originally made it meaningful.

The need may still be visible in the language of the work, but its meaning has moved.

## Why it matters

Small changes in user need wording can change the solution vector.

For example, these are not the same need:

- need to know options
- need to compare options
- need to judge which options are realistic
- need to decide which route to take
- need to protect future options

If a project treats one of these as if it were another, it can deliver activity without delivering public value.

## Link to Civic Design Intelligence

This is one of the theoretical problems Civic Design Intelligence may help expose by keeping needs, evidence, outcomes and decisions more traceable.
