# Lean provocations images

Put source images for the `Designing lean provocations` longform Notebook entry in this folder.

Recommended file:

```text
exconf-lean-provocations-hero.webp
```

The longform entry already points to:

```yaml
hero_image:
  src: notebook/lean-provocations/exconf-lean-provocations-hero.webp
```

Images in this folder are processed by Astro's image pipeline through `ResponsiveImage.astro`.
