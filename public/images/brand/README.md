# Brand assets

Put Happygeneralist brand images in this folder.

Recommended files:

```text
happygeneralist-logo-full.png
happygeneralist-mark.png
```

Use `happygeneralist-logo-full.png` for larger header or brand placements.

Use `happygeneralist-mark.png` for compact contexts where the full logo would become unreadable.

In Astro components, reference these assets with `import.meta.env.BASE_URL` so links work on both GitHub Pages project URLs and the eventual custom domain.
