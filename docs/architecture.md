# Site architecture

Happygeneralist.com is the public publishing layer for selected work from the wider Happygeneralist knowledge system.

It should not become the whole knowledge system.

## Core model

```text
Notebook
  where thoughts enter public form

Ideas
  where thoughts become named and portable

Tools
  where thoughts become usable

Labs
  where thoughts become spatial, applied and explorable

Themes
  where the whole system becomes navigable
```

## Design layers

### Standard layer

Used for homepage, notebook, ideas, tools, themes, about and most pages.

Characteristics:

- clear
- accessible
- content-led
- GOV.UK/x-gov adjacent
- restrained visual design
- low cognitive load

### Lab layer

Used for complex applied work and visual explanation.

Characteristics:

- modular
- spatial
- large-screen aware
- able to support diagrams and visualisation
- still accessible
- still semantically structured

## Repo relationships

```text
happygeneralist-site

  reusable visual, semantic and publishing system

product-bible

mt-genome

  public-service evidence and design-intelligence knowledge system

work-support
  private work scaffolding and support patterns
```

## Publishing principle

Repos hold working knowledge.

The site publishes shaped knowledge.

Labs compose knowledge into spatial public experiences.
